# PROJECT BRIEF
## Pharmacy Management System

### 1. Project Overview

Pharmacy Management System — дәріхананың негізгі жұмыс процестерін басқаруға арналған деректер базасы жобасы. Жүйе дәрілік заттарды, жеткізушілерді, қоймадағы қорларды, сатып алуларды, сатылымдарды және төлемдерді есепке алуға мүмкіндік береді.

### 2. Project Objective

Жобаның негізгі мақсаты — PostgreSQL деректер базасын пайдалана отырып, дәріхана жұмысын автоматтандыруға арналған құрылымды және функционалды деректер қорын құру.

### 3. Technologies Used

Database Management System: PostgreSQL

Database Tool: pgAdmin 4

Programming Language: SQL

Development Environment: Visual Studio Code

Version Control: Git and GitHub

### 4. Main System Modules

Medicine Management — дәрілік заттар туралы ақпаратты сақтау және басқару.

Inventory Management — қоймадағы дәрілердің санын бақылау.

Supplier Management — жеткізушілер туралы мәліметтерді басқару.

Purchase Management — дәрілерді сатып алу операцияларын тіркеу.

Sales Management — дәріханадағы сатылымдарды есепке алу.

Customer Management — тұтынушылар туралы ақпаратты сақтау.

Payment Management — төлемдерді тіркеу.

Expiration Control — дәрілердің жарамдылық мерзімін бақылау.

Prescription Control — рецепт бойынша берілетін дәрілерді бақылау.

Business Analytics — сатылымдар мен қойма қорларын талдау.

### 5. Database Structure

Жоба деректер базасында 16 негізгі кесте бар. Олар өзара Primary Key және Foreign Key арқылы байланысқан.

Деректердің дұрыстығын қамтамасыз ету үшін CHECK шектеулері, индекстер және байланыстар қолданылды.

### 6. Implemented SQL Features

Жобада SELECT, INSERT, UPDATE, DELETE командалары, JOIN, GROUP BY, HAVING, агрегаттық функциялар, ішкі сұраныстар және жиын операциялары қолданылды.

Сонымен қатар VIEW, INDEX, FUNCTION және PROCEDURE объектілері құрылды.

### 7. Expected Results

Жоба нәтижесінде дәріхана қызметінің негізгі деректерін сақтайтын және өңдейтін PostgreSQL деректер базасы жасалды.

Жүйе дәрілік заттардың қалдығын бақылауға, жарамдылық мерзімін тексеруге, сатылымдарды талдауға және қоймадағы тапшылықтарды анықтауға мүмкіндік береді.

### 8. Conclusion

Pharmacy Management System жобасы SQL және PostgreSQL мүмкіндіктерін тәжірибеде қолдануға арналған. Жоба барысында деректер базасын жобалау, кестелер құру, байланыстар орнату, SQL сұраныстарын орындау және бизнес-процестерді деректер базасы арқылы басқару дағдылары қолданылды.
